# Getting help

This is an unofficial, volunteer-run fan project for preservation and educational use. It is
not affiliated with or endorsed by gumi Inc., and the original game's support channels cannot
help with it.

## Where to ask

| You want to... | Go to |
|---|---|
| Ask how to build, configure or run something | [GitHub Discussions](https://github.com/joppe2001/bf-private-server/discussions) (Q&A) |
| Share an idea that is not a concrete request yet | [GitHub Discussions](https://github.com/joppe2001/bf-private-server/discussions) (Ideas) |
| Report a reproducible bug | [New issue: Bug report](https://github.com/joppe2001/bf-private-server/issues/new/choose) |
| Request a feature | [New issue: Feature request](https://github.com/joppe2001/bf-private-server/issues/new/choose) |
| Report a quest, unit, event or table the server does not serve | [New issue: Missing content](https://github.com/joppe2001/bf-private-server/issues/new/choose) |
| Report a security problem | Privately, through the **Security** tab; see [SECURITY.md](SECURITY.md) |

Search existing issues and discussions first; your question may already have an answer.

## Before you ask

- Read the [README](README.md), [CONTRIBUTING.md](CONTRIBUTING.md) (development setup per
  component), and [server/docs/DEVELOPMENT.md](server/docs/DEVELOPMENT.md).
- Say which component you are using (server, Workers, tools), your operating
  system, how you built it, and the commit you are on (`git rev-parse --short HEAD`).
- Include the exact command and its full output, or the relevant lines from the server log.
- Remove hostnames, IP addresses, tokens and account ids from anything you paste.

## What we cannot help with

- Obtaining the game client or game data. This repository contains code only; the data comes
  from public community preservation archives, which you obtain separately. Requests for APK
  downloads or copies of game files will be closed.
- Accounts, progress or purchases on any server run by someone else, including community
  servers built from this code. Contact that server's operators.
- The official game or anything owned by gumi Inc.
